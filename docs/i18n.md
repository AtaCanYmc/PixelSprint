# Internationalization

Translations live in `src/i18n/locales.ts`. The file exports a `Translations` interface and one object per language: `tr`, `en`, `fr`. TypeScript fails the build if a language is missing a key.

## Adding a Key

1. Add the key to the `Translations` interface.
2. Add a value in `tr`, `en` and `fr`.
3. Read it with `i18n.t('yourKey')` inside a component's update method.
4. Make sure that method is registered with `i18n.subscribe()` so the text changes when the language changes.
5. Run `npm run check-types`.

Hardcoded text in `index.html` is only the initial render. Components overwrite it on load, so every visible string must also be set from code.

## Adding a Language

1. Add the language code to the `Language` union in `src/types/index.ts`.
2. Copy the `en` object, rename it, and translate each value.
3. Add a `lang-btn` button with `data-lang="<code>"` to the Start Menu in `index.html`.

## Style Rules

- Button labels are short. No parenthetical explanations.
- Emoji prefixes stay identical across languages so emoji-only mode looks the same.
- Long explanations belong in tooltips or modal descriptions, not on buttons.
