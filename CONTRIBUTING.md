# Contributing to PixelSprint

## Setup

Requires Node.js 20 or later.

```bash
git clone https://github.com/AtaCanYmc/PixelSprint.git
cd PixelSprint
npm ci
npm run dev
```

`npm ci` also installs the Husky `pre-commit` hook, which formats staged files with Prettier.

## Before Opening a PR

```bash
npm run check-types
npm run build
```

Both must pass. CI runs `npm run build` on every pull request to `main`.

For UI changes, check the change in light and dark themes, with button labels on and off, and in TR, EN and FR. New visible strings go through `i18n.t()`. See [docs/i18n.md](docs/i18n.md).

For sync changes, open the same session in two browsers and confirm the event reaches the other side. See [docs/sync-protocol.md](docs/sync-protocol.md).

## Branches

| Prefix   | Use                        |
| :------- | :------------------------- |
| `feat/`  | New behavior.              |
| `fix/`   | Bug fix.                   |
| `docs/`  | Documentation only.        |
| `chore/` | Tooling, dependencies, CI. |

## Commit Messages

Releases are generated by [release-please](https://github.com/googleapis/release-please) from [Conventional Commits](https://www.conventionalcommits.org/).

| Type                                                       | Use                 | Version bump |
| :--------------------------------------------------------- | :------------------ | :----------- |
| `feat:`                                                    | New feature         | Minor        |
| `fix:`                                                     | Bug fix             | Patch        |
| `feat!:` or `BREAKING CHANGE:` footer                      | Incompatible change | Major        |
| `docs:`, `style:`, `refactor:`, `perf:`, `test:`, `chore:` | Everything else     | None         |

Examples:

```text
feat(timer): lock card entry when the timer expires
fix(export): escape XML entities in xlsx cells
docs(readme): document PeerJS signaling
```

## Pull Requests

1. Fork and branch from `main`.
2. Keep one concern per PR.
3. Fill in the PR template, including how you verified the change.
4. Squash-merge with a Conventional Commit title.
