## Reporting a Vulnerability

We take the security and privacy of **PixelSprint** seriously. PixelSprint operates as a 100% client-side Progressive Web Application (PWA) storing retrospective session cards exclusively in the user's browser `localStorage`. No telemetry, tracking, or sensitive user data is transmitted to external servers.

If you discover a security vulnerability, please follow these guidelines:

### How to Report

1. **Do NOT open a public issue** on GitHub for security vulnerabilities.
2. Send an email describing the vulnerability to the project maintainers.
3. Include detailed steps to reproduce the issue, potential impact, and any suggested mitigations.

### Response Timelines

- **Acknowledgement**: Within 48 hours of receiving your report.
- **Assessment**: Within 7 business days.
- **Fix Release**: Vulnerability patches will be released as soon as verified.

Thank you for helping keep PixelSprint secure!
